# Tappa 1.0 — Stabilità e prestazioni

- **Stato:** in programma
- **Milestone GitHub:** `v1.0`

## 1. Obiettivo

Un CAD 2D affidabile per il lavoro reale: veloce sui disegni grandi, che non perde
mai il lavoro, documentato.

## 2. Confini

**Dentro:** nessuna nuova funzione. Prestazioni su disegni grandi; salvataggio
automatico e recupero dopo un crash; test con dati casuali (*fuzzing*) di DXF e
formato nativo; correzione di tutti i bug aperti con priorità alta; manuale utente
completo; guida per sviluppatori aggiornata.

**Fuori:** tutto ciò che è una funzione nuova, compreso il 3D.

## 3. Criteri di chiusura

- [ ] Disegno di 1.000.000 di segmenti: apertura sotto 5 s, zoom e pan fluidi
      (almeno 30 fotogrammi al secondo) su un computer di fascia media
- [ ] Recupero automatico verificato chiudendo il programma a forza
- [ ] Fuzzing degli import per 24 ore senza crash
- [ ] Nessun bug con priorità alta aperto
- [ ] Manuale utente che copre tutti i comandi

## 4. Progetto di massima

- **Rendering:** con ogni probabilità un backend OpenGL o Vulkan per `Painter`,
  reso possibile dall'ADR 0001 senza toccare il resto. Decisione con un ADR, dopo
  misure fatte sul backend QPainter.
- **ADR richiesti:** backend di rendering accelerato; politica di salvataggio
  automatico.

# Tappa 0.2 — Comandi e annullamento

- **Stato:** in preparazione
- **Milestone GitHub:** `v0.2`
- **Apertura:** — **Chiusura:** —

## 1. Obiettivo

L'utente disegna la sua prima polilinea: scrive `PLINE` (o `PL`) sulla riga di
comando, indica i punti con il mouse o scrivendo le coordinate, e può annullare e
ripetere il lavoro con `Ctrl+Z` e `Ctrl+Y`.

## 2. Confini

**Dentro:**
- riga di comando in stile AutoCAD con storico dei messaggi;
- comando `PLINE` con soli segmenti retti e le opzioni *Close* e *Undo*;
- coordinate scritte: assolute, relative, polari, distanza diretta (ADR 0005);
- `Invio` a riga vuota ripete l'ultimo comando;
- annulla e ripeti, da menu, da tastiera e con i comandi `U`/`UNDO` e `REDO`;
- anteprima elastica del segmento che segue il puntatore.

**Fuori:**
- archi nella polilinea e comando `LINE` → tappa 0.4;
- selezione, cancellazione, snap, orto → tappa 0.3;
- salvataggio su file → tappa 0.5;
- traduzione dei testi → tappa 0.9.

## 3. Criteri di chiusura

- [ ] `PLINE` e `PL` avviano il comando, in maiuscolo o minuscolo
- [ ] I punti si indicano con il clic sinistro e con tutte le sintassi dell'ADR 0005
- [ ] Durante il comando si vede il segmento elastico verso il puntatore
- [ ] `Invio`, spazio o clic destro concludono la polilinea (almeno 2 punti)
- [ ] `C` chiude la polilinea (almeno 3 punti); `U` toglie l'ultimo punto
- [ ] `Esc` annulla il comando senza lasciare nulla nel disegno
- [ ] Una scrittura non valida mostra un messaggio e ripete la domanda
- [ ] `Invio` a riga vuota ripete l'ultimo comando
- [ ] `Ctrl+Z` toglie l'intera polilinea, `Ctrl+Y` la ripristina con lo stesso id
- [ ] Annulla e ripeti sono disattivati mentre un comando è in corso
- [ ] Moduli `edit` e `cmd` senza dipendenze da Qt, con test
- [ ] CI verde sui tre sistemi; prova manuale eseguita sui tre sistemi
- [ ] Manuale utente dei comandi e note di rilascio scritti

## 4. Progetto di massima

Vedi l'ADR 0005. In sintesi:

```
core   Document: find, remove, restore
edit   Editor, Transaction, UndoStack
cmd    Input, Prompt, Command, CommandRegistry, CommandRunner,
       coordinate parser, PlineCommand
render renderPreview()
app    CommandLine widget, collegamento vista ↔ CommandRunner, menu Modifica
```

Flusso di un clic: `CadView` converte il clic in coordinate del disegno →
`CommandRunner::submit(PointInput)` → `PlineCommand` aggiunge il vertice →
`CadView` ridisegna, chiedendo l'anteprima al comando attivo.

**Rischi.** La gestione della tastiera tra vista e riga di comando è il punto più
delicato su macOS (scorciatoie con `Cmd`). Va provata a mano presto, già con P8.

- **Difficoltà:** media

  ```cpp
  namespace tg::edit {
  class Editor {
  public:
      explicit Editor(core::Document& document);
      [[nodiscard]] const core::Document& document() const;

      void beginTransaction(std::string name);  // assert se già aperta
      core::EntityId add(core::Entity entity);  // solo dentro una transazione
      bool remove(core::EntityId id);           // solo dentro una transazione
      void commit();                            // vuota: nessun passo di annullamento
      void rollback();                          // annulla le operazioni della transazione
      [[nodiscard]] bool inTransaction() const;

      [[nodiscard]] bool canUndo() const;
      [[nodiscard]] bool canRedo() const;
      [[nodiscard]] std::string undoName() const;  // nome del passo che verrebbe annullato
      [[nodiscard]] std::string redoName() const;
      bool undo();  // false se non c'è nulla o se una transazione è aperta
      bool redo();

      using Listener = std::function<void()>;
      void setChangeListener(Listener listener);  // chiamato dopo commit, rollback, undo, redo
  };
  }
  ```
  Ogni transazione registra la lista delle operazioni elementari (aggiunto record,
  tolto record) e sa applicarle al contrario. Una nuova `commit` cancella la pila
  dei passi da ripetere.

  ripristina gli stessi id; rollback; commit vuota; nuova transazione dopo undo che
  cancella il redo; chiamate al listener; nomi dei passi.
- **Fatto quando:** i test passano; nessun accesso a `Document` modificabile fuori

### P5 — Motore dei comandi

- **Difficoltà:** impegnativa
- **Dipende da:** P3, P4
- **Moduli:** cmd
- **File:** `cmd/include/tg/cmd/{input,command,command_registry,command_runner}.hpp`,
  sorgenti corrispondenti, `tests/cmd/command_runner_test.cpp`
- **Cosa fare:**
  ```cpp
  namespace tg::cmd {
  struct PointInput { core::Vec2 point; };
  struct KeywordInput { std::string keyword; };   // forma canonica, es. "Close"
  struct ConfirmInput {};                         // Invio, spazio, clic destro
  struct CancelInput {};                          // Esc
  using Input = std::variant<PointInput, KeywordInput, ConfirmInput, CancelInput>;

  struct Keyword { std::string name; std::string shortcut; };  // {"Close", "C"}
  struct Prompt { std::string text; std::vector<Keyword> keywords; };

  struct CommandContext {
      edit::Editor& editor;
      std::optional<core::Vec2> lastPoint;           // aggiornato dal comando
      std::function<void(std::string)> message;      // scrive nello storico
  };

  enum class Status { Continue, Finished };

  class Command {
  public:
      virtual ~Command() = default;
      virtual void start(CommandContext& context) = 0;    // apre la transazione
      virtual Status handle(CommandContext& context, const Input& input) = 0;
      virtual void pointerMoved(const core::Vec2& point) = 0;
      [[nodiscard]] virtual Prompt prompt() const = 0;
      [[nodiscard]] virtual std::span<const core::Entity> preview() const = 0;
  };

  class CommandRegistry {   // nomi e alias senza distinzione maiuscole/minuscole
  public:
      using Factory = std::function<std::unique_ptr<Command>()>;
      void add(std::string name, std::vector<std::string> aliases, Factory factory);
      [[nodiscard]] std::unique_ptr<Command> create(std::string_view nameOrAlias) const;
      [[nodiscard]] std::optional<std::string> canonicalName(std::string_view nameOrAlias) const;
  };

  class CommandRunner {
  public:
      CommandRunner(const CommandRegistry& registry, edit::Editor& editor);
      void submitText(std::string_view text);  // riga di comando (testo vuoto = Invio)
      void submit(const Input& input);         // mouse e tasti
      void pointerMoved(const core::Vec2& point);
      [[nodiscard]] bool isActive() const;     // un comando è in corso
      [[nodiscard]] std::string promptText() const;  // "Command:" se inattivo
      [[nodiscard]] std::span<const core::Entity> preview() const;
      void setMessageSink(std::function<void(std::string)> sink);
  };
  }
  ```
  Regole di `submitText` quando un comando è attivo: testo vuoto → `ConfirmInput`;
  corrisponde a una parola chiave del prompt (nome o scorciatoia, senza distinzione
  maiuscole/minuscole) → `KeywordInput`; è una coordinata valida e risolvibile →
  `PointInput`; altrimenti messaggio "Invalid point or option." e il prompt resta.
  Quando nessun comando è attivo: testo vuoto ripete l'ultimo comando; un nome
  sconosciuto produce "Unknown command: <nome>." I comandi `U`, `UNDO` e `REDO` sono
  gestiti dal runner stesso e funzionano solo da inattivo. `CancelInput` chiude il
  comando con `rollback`. Se il comando termina, il runner verifica che la
  transazione sia stata chiusa.
- **Test richiesti:** con un comando finto: avvio per nome e alias; parole chiave;
  coordinate valide e non valide; Esc con rollback; ripetizione con Invio; `U` e
  `REDO`; comando sconosciuto; messaggi prodotti.
- **Fatto quando:** i test passano e il runner non conosce nessun comando concreto.

  - Nome della transazione: `Polyline`.
- **Test richiesti:** ogni ramo qui sopra, pilotato attraverso `CommandRunner`;
  verifica dei vertici e del flag di chiusura nel documento; Esc a metà.

## 7. Prova manuale

Da eseguire su Windows, Linux e macOS prima della chiusura:

1. Avviare il programma, scrivere `pl` con la vista in primo piano: il testo deve
   comparire nella riga di comando.
2. Indicare tre punti con il mouse, osservando l'anteprima elastica; `Invio`.
3. `Invio` a riga vuota: deve ripartire `PLINE`. Scrivere `0,0`, `@50,0`,
   `@50<90`, `0,50`, poi `c`: si ottiene un quadrato chiuso di lato 50.
4. Avviare `PL`, due punti, `u`, `u`: si torna a "Specify start point". `Esc`:
   nel disegno non resta nulla.
5. Avviare `PL`, un punto, poi scrivere `@10`: deve comparire un messaggio di
   errore e la domanda resta la stessa. `Esc`.
6. `Ctrl+Z` due volte, `Ctrl+Y` due volte (su macOS `Cmd+Z`, `Cmd+Shift+Z`).
7. Durante un comando, verificare che *Undo* nel menu sia disattivato.

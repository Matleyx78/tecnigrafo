# Tappa 0.1 — Fondamenta

- **Stato:** chiusa
- **Milestone GitHub:** `v0.1`
- **Apertura:** 2026-10-15 — **Chiusura:** 2026-10-15

## 1. Obiettivo

Una finestra su Windows, Linux e macOS che mostra un disegno fatto di polilinee,
navigabile con zoom e pan come in AutoCAD, costruita su un'architettura pronta a
crescere.

## 2. Confini

**Dentro:** architettura a strati (ADR 0001), strumenti e regole (ADR 0002, 0003),
modello geometrico 2D con polilinee e archi (ADR 0004), viewport, griglia, disegno
attraverso un'interfaccia astratta, applicazione Qt, test, CI, documenti di governo.

**Fuori:** qualunque interazione di disegno (0.2), selezione (0.3), file (0.5).

## 3. Criteri di chiusura

- [x] Compilazione senza avvisi con gli avvisi trattati come errori
- [x] Test di geometria, viewport e disegno della scena
- [x] Prova di avvio dell'applicazione senza schermo (`app_smoke`)
- [x] Analisi statica senza segnalazioni
- [x] Zoom verso il cursore, pan con il tasto centrale, zoom estensioni
- [x] `core` e `render` senza dipendenze da Qt
- [x] Documenti di governo, regole di contributo, ADR 0001-0004

Vedi gli ADR 0001-0004.

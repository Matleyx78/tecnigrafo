# Icone di Tecnigrafo

Icone SVG disegnate per Tecnigrafo in un unico stile, monocromatiche: il colore
lo dà il tema (`currentColor`).

- **Licenza:** quella del progetto, GPL-3.0-or-later. Ogni file ha
  l'intestazione SPDX in un commento XML.
- **Origine:** tutte le icone sono nostre. Nessuna è copiata, né ridisegnata,
  da altri programmi o raccolte ([ADR 0009](../../docs/adr/0009-interfaccia-grafica.md),
  punto 4).
- **Regole di disegno, elenco e come aggiungere un'icona:**
  [docs/ICONE.md](../../docs/ICONE.md).

Il nome di ogni file è quello del campo `icon` dell'azione che lo usa
(`draw-line.svg` per `draw.line`). Il programma le legge dalle risorse
`:/tg/icons/`.
